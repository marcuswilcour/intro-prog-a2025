# Exercices sur les types de données

Pour chaque situation, donner un type de donnée approprié et proposer un nom de variable acceptable.

Choisir parmi `byte`, `short`, `int`, `long`, `float`, `double`, `char`, `boolean`, `String`.

|Variable|Type|Nom|
|---|---|---|
|1. Le salaire horaire|float|salaireHoraire|
|2. Le prénom du client|String|nomClient|
|3. Un code postal|String|codePostal|
|4. L'âge d'une personne|byte|agePersonne|
|5. Le montant total d'une facture|float|totalFacture|
|6. La date courante|short|dayInYear|
|7. Le genre de quelqu'un|String|genrePersonne|
|8. Le statut de retraité d'un travailleur|boolean|statutRetraite|
|9. Un nombre de billes|int|nbBilles|
|10. L'adresse de l'étudiant|String|addresseEtudiant|
|11. Une note au bulletin|float|noteFinale|
|12. Le nombre d'étoiles dans l'univers|long|totalEtoilesUnivers|
